Neighbourhood Map

Enter a property address and press Show map. You'll get the most popular restaurants, nearby schools and parks, each with Google rating and review count.

Google Maps API key

Paste a Google Cloud API key with Maps JavaScript API, Places API (New), Geocoding API and Maps Static API enabled. It is stored only in this browser. (The site owner can instead set it once in config.js.) Restrict the key to your website address in Google Cloud so it can't be misused.
