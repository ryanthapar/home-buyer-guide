Build the sales map data

Private tool. It is not linked from the guide. Everything runs in this browser: your MLS export files are read here and are never uploaded. Only the address lookups go to Google.

How to use it

  1. Choose the MLS transaction exports (.xlsx or .csv). You can pick all years at once, or add new years later.
  2. Press Read files, then Look up locations. 1,700 addresses take about 4 minutes. A lookup you have already done is remembered in this browser.
  3. Press Download sales.json and put it in the data folder of the repo (replacing the old file).

The file only holds an approximate pin (rounded to about 100 m), the year, the property type, the city and the type of transaction. Street addresses, prices, MLS numbers and agent names are not kept.
